# windows/

PowerShell-скрипты для Windows (RD Gateway) и автоустановка Windows.

Скрипты для 1С вынесены в [`1c/`](../1c/).

| Скрипт | Назначение |
|---|---|
| `Update-RDGWCertificate.ps1` | Получение/продление сертификата Let's Encrypt через Posh-ACME (DNS-плагин Beget) и установка на RD Gateway. Для планировщика: одно задание раз в сутки с наивысшими правами. Сохранять в UTF-8 with BOM. |

## oobe/

Автоустановка и полная настройка рабочей станции Windows — файл ответов,
установка ПО с Synology NAS / winget, правки реестра. Подробности, раскладка
дистрибутивов на NAS и диагностика: [`oobe/README.md`](oobe/README.md).

| Файл | Назначение |
|---|---|
| `AutoUnattend.xml` | Файл ответов для чистой установки с нуля: локали, обход требований Win11, локальный администратор `Admin`, запуск пост-установки. |
| `UnattendOOBE.xml` | Файл ответов только для прохода `oobeSystem` — повторный прогон OOBE через `sysprep /oobe`. |
| `oobe.ps1` | Скачивает и проверяет файл ответов, раскладывает пост-установочные файлы, запускает `sysprep /oobe /reboot /unattend:…`. |
| `postinstall.ps1` | Пост-установка при первом входе: ПО, правки реестра, системные настройки. |
| `postinstall.json` | Конфигурация пост-установки: NAS, список ПО, правки реестра, системные параметры. |
| `office/*.xml` | Конфигурации Office Deployment Tool (Office LTSC 2021 и Microsoft 365 Apps). |

> ⚠️ Создаётся локальный администратор `Admin/Admin` с однократным автовходом —
> смените пароль сразу после установки. Пароль NAS в репозиторий не кладём:
> передавайте его через `-NasPassword` (см. `oobe/README.md`).
